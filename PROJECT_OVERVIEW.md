# PROJECT OVERVIEW

# Nama Project

Sistem Pendukung Keputusan Dalam Perhitungan Harga Kelapa Sawit Menggunakan Metode MOORA

---

# Tujuan Sistem

Membangun aplikasi berbasis web yang mampu membantu proses penentuan harga TBS kelapa sawit menggunakan metode MOORA sehingga menghasilkan keputusan yang objektif dan transparan.

---

# Rumusan Masalah

1. Bagaimana membangun sistem pendukung keputusan yang mampu menentukan harga kelapa sawit secara objektif?

2. Bagaimana menerapkan metode MOORA pada proses perhitungan harga TBS kelapa sawit?

---

# Tujuan Penelitian

- Menerapkan metode MOORA.
- Menghasilkan sistem berbasis web.
- Membantu petani memperoleh informasi harga yang lebih objektif.

---

# Manfaat

## Bagi Petani

Memperoleh informasi harga yang transparan.

## Bagi Peneliti

Menambah wawasan implementasi SPK.

## Bagi Pengembang

Sebagai contoh implementasi metode MOORA pada Laravel.

---

# Batasan Sistem

- Sistem berbasis web
- Menggunakan Laravel
- Menggunakan MySQL
- Menggunakan metode MOORA
- Data berasal dari data sekunder
